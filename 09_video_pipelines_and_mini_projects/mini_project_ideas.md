# Mini Project Ideas

## 目标

给你几个范围可控、适合当前学习阶段的小型视频项目方向，让你在真正动手时不会因为题目太大而失控。

## 项目 1：实时边缘观察器

### 输入

- `resources/videos/dog.mp4`
- `resources/videos/kitten.mp4`

### 处理链路

- 读取视频帧
- 灰度化
- 模糊
- Canny 边缘提取
- 显示结果

### 输出

- 原始帧
- 边缘结果帧

### 难点

- 参数变化带来的帧间抖动
- 视频分辨率与速度的平衡

### 建议顺序

- 先做 Python
- 再做 C++

## 项目 2：实时轮廓高亮器

### 输入

- `resources/videos/dog.mp4`
- `resources/videos/kitten.mp4`

### 处理链路

- 逐帧读取
- 预处理
- 边缘或阈值提取
- 轮廓检测
- 按规则过滤
- 把保留轮廓画回画面

### 输出

- 带轮廓标注的视频帧

### 难点

- 连续帧中的轮廓不稳定
- 小噪声轮廓容易闪烁

### 建议顺序

- 先验证静态单帧逻辑
- 再放进视频循环

## 项目 3：原图 / 处理图对照播放器

### 输入

- 任意已有视频

### 处理链路

- 逐帧读取
- 对当前帧做一种处理
- 把原图和处理图并排显示

### 输出

- 左边原图，右边处理结果

### 难点

- 两路显示同步
- 确保视觉对比清晰

### 建议顺序

- 先做边缘版本
- 再做轮廓版本

## 项目 4：小型综合 live pipeline

### 输入

- 一段已有视频

### 处理链路

- 读取帧
- 预处理
- 边缘或阈值提取
- 轮廓过滤
- 目标标注
- 显示处理结果

### 输出

- 带有目标标记、轮廓或统计信息的实时画面

### 难点

- 处理步骤较多，速度容易下降
- 参数之间会互相影响

### 建议顺序

- 先用 Python 把项目跑通
- 再用 C++ 做工程化复现

## 选题建议

如果你想按最稳妥路线推进：

1. 先做“实时边缘观察器”
2. 再做“实时轮廓高亮器”
3. 最后再做“小型综合 live pipeline”

## 做项目时建议回答的问题

每完成一个项目，尽量写下：

- 输入是什么
- 每帧处理了哪些步骤
- 输出想表达什么
- 最慢的环节在哪里
- 如果继续迭代，你下一步想优化什么
