# 实验：实时边缘处理

## 实验目标

把静态图像中的边缘检测迁移到连续视频帧中，观察参数、噪声与实时稳定性之间的关系。

## 对应代码

- Python：`python/realtime_edges.py`
- C++：`cpp/realtime_edges.cpp`

## 第一性原理

边缘检测在视频中本质上仍然是在处理单帧图像，只不过你现在要面对的是：

- 每一帧都要重复做同样的处理
- 相邻帧之间的细小变化会被放大成闪烁或抖动
- 参数是否稳定会直接影响连续显示体验

## 实验步骤

1. 选择 `resources/videos/dog.mp4` 或 `resources/videos/kitten.mp4`
2. 写出逐帧读取循环
3. 对每一帧做灰度化和模糊处理
4. 执行 Canny 边缘检测
5. 显示原始帧和边缘结果
6. 调整参数并比较帧间稳定性
7. 在 C++ 中复现同样流程

## 需要观察的点

- 同一组参数在连续帧中是否稳定
- 分辨率变化是否影响处理速度
- 模糊是否能减少边缘噪声
- 边缘结果是否会在相邻帧之间明显闪烁

## 预期效果

完成后你应该能：

- 跑通一个最基础的实时图像处理循环
- 在视频中实时看到边缘变化
- 解释为什么视频里的参数稳定性比静态图更重要

## 常见问题

### 1. 结果抖动很明显

通常说明参数对噪声过于敏感，或者预处理不足。

### 2. 速度太慢

通常说明：

- 分辨率太高
- 每帧处理步骤过多
- 显示逻辑不够简洁

### 3. 看不出参数差异

可能是视频场景过于简单，也可能是你调整幅度太小。

## 拓展练习

1. 比较原分辨率和缩小分辨率下的实时效果
2. 对比“先模糊再 Canny”和“直接 Canny”
3. 记录一组最稳定参数和一组最不稳定参数
4. 对照 Python 与 C++ 在实时调试体验上的差异
