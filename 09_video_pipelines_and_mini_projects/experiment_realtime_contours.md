# 实验：实时轮廓处理

## 实验目标

观察轮廓提取从静态图像迁移到连续视频后，会遇到哪些新的稳定性问题，并学会通过规则过滤提升结果质量。

## 对应代码

- Python：`python/realtime_contours.py`
- C++：`cpp/realtime_contours.cpp`

## 第一性原理

轮廓本质上是前景结构的边界表达。放到视频里之后，你不只要关心“这一帧能不能提取到轮廓”，还要关心：

- 连续帧中的轮廓是否稳定
- 噪声轮廓会不会闪烁
- 同一个目标在相邻帧中是否能保持近似一致

## 实验步骤

1. 选择一段已有视频
2. 完成逐帧读取与基础预处理
3. 用 threshold 或 Canny 生成轮廓输入
4. 提取当前帧中的全部轮廓
5. 加入最小面积等过滤规则
6. 把保留轮廓画到当前帧上
7. 观察连续帧中的变化
8. 再在 C++ 中复现同一逻辑

## 需要观察的点

- 小噪声轮廓是否频繁闪烁
- 同一目标在相邻帧中的轮廓大小是否稳定
- 面积阈值改变后，画面中的保留目标如何变化
- 不同视频素材上过滤规则是否同样有效

## 预期效果

完成后你应该能：

- 在视频里实时看到轮廓提取和过滤结果
- 解释为什么动态场景下过滤规则更重要
- 说明哪些轮廓是目标，哪些只是噪声

## 常见问题

### 1. 整个画面上都是小轮廓

通常说明噪声较多，或者阈值 / 边缘参数过于敏感。

### 2. 目标轮廓忽大忽小

通常说明：

- 输入不稳定
- 过滤规则不够稳
- 连续帧中的细微变化被放大了

### 3. 一组规则只适合某一段视频

说明你当前规则的泛化性还不够，需要重新设计过滤标准。

## 拓展练习

1. 比较 threshold 入口和 Canny 入口的实时效果
2. 只用面积过滤，再加长宽比过滤，比较结果差异
3. 在结果图上显示保留轮廓数量
4. 对照 Python 与 C++ 版本的结构组织差异
