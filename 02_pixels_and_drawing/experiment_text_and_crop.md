# 实验：文字与裁剪

## 实验目标

掌握文本绘制与 ROI 裁剪，理解“图像局部区域”这个概念。

## 对应代码

- Python：`python/add_text.py`
- Python：`python/cropping_image.py`

## 第一性原理

裁剪不是“特殊 API 魔法”，而是矩阵切片。

当你写出一个范围时，本质是在取原矩阵中的子矩阵。

## 实验步骤

1. 在空白图上写文字
2. 修改字体、字号、位置与线宽
3. 读取真实图片并裁剪一块区域
4. 对比原图和 ROI

## 预期效果

- 能理解 ROI 是局部矩阵视图/区域
- 能把文字稳定放到指定位置

## 拓展练习

1. 给裁剪区域画边框
2. 在原图和裁剪图同时显示尺寸信息
3. 尝试裁出超出边界的区域并观察结果
