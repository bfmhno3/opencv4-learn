# 实验：读取图片

## 实验目标

学会用 OpenCV 正确读取一张或多张图片，并理解“读图成功”到底意味着什么。

## 对应代码

- Python：`python/read_image.py`
- C++：后续补充对应版本

## 第一性原理

`imread` 做的事情不是“把图片显示出来”，而是：

1. 从磁盘读取文件字节
2. 解析图像编码格式
3. 转换成内存中的像素矩阵
4. 返回给程序进行后续处理

所以，读图的本质是 **文件 -> 矩阵**。

## 实验步骤

1. 准备 `resources/photos/` 中的图片
2. 运行脚本，遍历目录下所有文件
3. 观察每张图是否都能弹窗显示
4. 尝试故意修改一个错误路径，观察失败现象

## 需要观察的点

- 图片能否正确读取
- 不同文件名是否都能正常处理
- 如果路径错误，`img` 会是什么状态
- 多个窗口是否都能正常显示

## 预期效果

- 所有合法图片都能显示
- 错误路径会导致空图像，后续 `imshow` 可能报错

## 常见问题

### 1. 图片不显示

通常是路径错误，或者图片没有被成功读取。

### 2. 窗口一闪而过

通常是没有正确调用 `waitKey`。
