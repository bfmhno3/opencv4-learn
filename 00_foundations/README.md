# 00 Foundations

## 阶段定位

这是预备阶段。它更像整套路线的导学与底层心智模型构建，不要求你先写很多代码，而是帮助你在进入后续实验前先建立统一理解。

## 阶段目标

这一阶段不急着调用很多 OpenCV API，而是先回答几个根问题：

- 图像到底是什么？
- OpenCV 为什么把图像表示成矩阵？
- 坐标、通道、颜色顺序、数据类型为什么重要？
- Python 的 `numpy.ndarray` 和 C++ 的 `cv::Mat` 有什么共性与差异？

## 你要建立的心智模型

1. **图像是矩阵**：宽、高、通道共同定义了一张图。
2. **像素是最小信息单元**：每个像素包含位置和数值。
3. **颜色是编码方式**：BGR、RGB、HSV、LAB 都是不同的表达。
4. **OpenCV 是一套矩阵变换工具**：大部分视觉操作，本质上都是对矩阵做重排、变换或局部计算。
5. **Python 与 C++ 只是接口不同**：核心算法思想不变。

## 阶段完成标准

完成后你应该能解释：

- 为什么彩色图通常是 `(height, width, 3)`
