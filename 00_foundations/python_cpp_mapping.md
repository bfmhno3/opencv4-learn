# Python 与 C++ 的 OpenCV 映射关系

## 目标

在学习过程中，不把 Python 和 C++ 当成两套完全独立的知识，而是把它们看成同一套 OpenCV 思想的两种表达。

## 一组最基本的对应

| 概念 | Python | C++ |
|---|---|---|
| 读取图片 | `cv.imread(path)` | `cv::imread(path)` |
| 显示窗口 | `cv.imshow(name, img)` | `cv::imshow(name, img)` |
| 等待按键 | `cv.waitKey(0)` | `cv::waitKey(0)` |
| 图像对象 | `numpy.ndarray` / `cv.Mat` | `cv::Mat` |
| 颜色转换 | `cv.cvtColor(img, code)` | `cv::cvtColor(img, out, code)` |

## 最核心的差异

### 1. Python 更适合快速建立直觉

优点：

- 代码短
- 反馈快
- 更适合做小实验

### 2. C++ 更适合理解类型、内存与工程组织

优点：

- 类型更明确
- 编译期暴露更多问题
- 更接近高性能视觉项目的真实工程环境

## 一个重要原则

你不是在学两套 OpenCV，而是在学：

- 同一套视觉概念
- 同一套数据流
- 两种不同的语言表达方式

## 建议学习方法

1. 先用 Python 写出最短可运行版本
2. 再用 C++ 重写同一实验
3. 对比输入、输出、中间变量和 API 形式
4. 记录差异，但不要把差异误认为“概念不同”

## 后续阶段如何应用

后面的每个阶段都应尽量回答这三个问题：

1. 这个实验在处理什么样的矩阵？
2. Python 版本为什么更容易写？
3. C++ 版本为什么更适合理解底层与工程化？
