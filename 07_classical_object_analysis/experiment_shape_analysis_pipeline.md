# 实验：形状分析主流程

## 实验目标

把多步图像处理操作串成一个完整流程，从像素矩阵中提取出可测量、可解释的目标区域。

## 对应代码

- Python：`python/shape_analysis_pipeline.py`
- C++：`cpp/shape_analysis_pipeline.cpp`

## 第一性原理

形状分析不是“识别物体是什么”，而是先回答一个更基础的问题：

- 图像里哪些区域可以被当成一个独立目标？
- 这些目标的几何特征是什么？

从第一性原理看，你是在把：

- 连续像素
- 变成离散区域
- 再变成可量化的描述量

## 实验步骤

1. 从 `resources/photos/` 中选择一张边界较清晰的图片
2. 对图片做灰度化和模糊处理
3. 选择阈值化或 Canny 作为前景提取入口
4. 如果噪声较多，可加入膨胀/腐蚀等形态学操作
5. 提取轮廓
6. 为每个轮廓计算面积、周长、包围框等特征
7. 把结果画回原图并标注出来
8. 用同样思路在 C++ 中复现一遍

## 需要观察的点

- 不同预处理方式是否会改变轮廓质量
- 阈值过高或过低时会发生什么
- Canny 的阈值变化会怎样影响候选轮廓
- 小噪声轮廓是否会显著影响结果
- 你认为“主要目标”的轮廓，是否真的被正确保留下来

## 预期效果

完成后你应该能得到：

- 一张包含目标标注的结果图
- 对主要轮廓的面积、周长、包围框等描述
- 一套你能解释清楚的处理流程

## 常见问题

### 1. 轮廓太多

通常说明：

- 阈值不合适
- 噪声太多
- 图像背景过于复杂

### 2. 主要目标没有被提取出来

通常说明：

- 前景与背景分离不充分
- 边缘断裂
- 预处理不足

### 3. 包围框位置不合理

通常说明：

- 提取到的轮廓本身就不完整
- 过滤规则还不稳定

## 拓展练习

1. 分别用 threshold 和 Canny 做入口，比较结果差异
2. 对两张不同背景复杂度的图片重复同一流程
3. 给轮廓增加编号，并统计保留目标总数
4. 比较 Python 与 C++ 版本在实现表达上的不同
