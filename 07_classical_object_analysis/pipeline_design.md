# Pipeline Design

## 目标

这一阶段的重点不是再学一个单独算子，而是学会把多个基础操作组合成一条**经典视觉分析管线**。你要做的不是“调用几个函数”，而是从输入图像一路推到可解释的结构结果。

## 什么是经典视觉分析流程

从第一性原理看，经典视觉分析通常是在做下面这件事：

1. 输入一张像素矩阵
2. 通过预处理降低噪声、增强结构
3. 把前景从背景中分离出来
4. 提取候选区域或轮廓
5. 计算这些区域的几何特征
6. 用规则过滤无关目标
7. 把结果重新画回图像并解释出来

也就是说，你最终要得到的不是“处理后的图片”，而是：

- 哪些区域值得关注
- 为什么这些区域被保留下来
- 它们的面积、周长、包围框等量化特征是什么

## 一条典型管线

你可以围绕这条通用链路来实现：

`输入图像 -> 灰度化 -> 模糊 -> 阈值化或 Canny -> 形态学优化 -> 轮廓提取 -> 特征计算 -> 规则过滤 -> 可视化`

### 什么时候优先用阈值化

适合：

- 前景与背景亮度差比较明显
- 目标边界较完整
- 你想直接得到二值区域

### 什么时候优先用 Canny

适合：

- 你更关注边界而不是完整填充区域
- 目标轮廓清晰，但前景和背景未必容易直接二值分开
- 你想观察边缘结构的变化

### 什么时候加形态学

适合：

- 二值图里有很多小噪点
- 边缘断裂，需要连接
- 前景区域内部有小洞，需要平滑或填补

## Python 与 C++ 如何对应

### Python 路线

优先目标：

- 快速试参数
- 快速看中间结果
- 快速建立对整条管线的直觉

建议你先在 Python 中完成：

- `python/shape_analysis_pipeline.py`
- `python/contour_filtering_pipeline.py`

### C++ 路线

优先目标：

- 明确每一步输入输出的数据类型
- 更清楚地组织流程与中间变量
- 对比同一流程在两种语言中的 API 表达

建议你随后在 C++ 中复现：

- `cpp/shape_analysis_pipeline.cpp`
- `cpp/contour_filtering_pipeline.cpp`

### 对照时重点看什么

- Python 中一行完成的操作，在 C++ 中如何拆开
- 中间图像变量如何命名和传递
- 同一组参数在两种语言中是否得到一致结果
- 最终标注图是否在视觉上保持一致

## 输入资源建议

优先从 `resources/photos/` 中挑选：

- 边界比较清晰的图片
- 背景相对简单的图片
- 包含几个主要目标、而不是过度复杂场景的图片

建议先从以下类型开始：

- `cat.jpg` / `cats.jpg`：适合观察主要轮廓
- `park.jpg`：适合分析复杂背景下边缘和轮廓噪声

如果你发现现有图片不够适合形状分析，后续可补充：

- 规则几何图形图片
- 高对比度前景/背景图片
- 简单背景上的多个独立目标图片

## 输出结果应该长什么样

一个合格的结果，不只是“程序能跑”，而是应该至少包含：

- 原图
- 预处理后的关键中间结果
- 提取到的候选轮廓图
- 过滤后的最终结果图
- 目标的面积、周长、包围框等标注信息

## 实现时检查清单

开始实现前，先确认：

- 你选的图片是否真的适合轮廓分析
- 你是否已经决定使用 threshold 还是 Canny 作为主入口
- 你是否定义了过滤规则
- 你是否准备展示中间结果，而不是只看最终结果
- 你是否会在 Python 和 C++ 中保持同一任务目标
