# 实验：轮廓过滤流程

## 实验目标

学习如何不只是“找到轮廓”，而是通过规则过滤真正有意义的目标区域。

## 对应代码

- Python：`python/contour_filtering_pipeline.py`
- C++：`cpp/contour_filtering_pipeline.cpp`

## 第一性原理

轮廓提取往往会得到很多候选区域，但并不是每个候选区域都值得保留。

所以真正的分析任务通常包含两步：

1. 先把所有候选结构找出来
2. 再用规则筛掉你不关心的部分

也就是说，你是在做“结构提取”之后的“结构筛选”。

## 实验步骤

1. 选择一张可能会产生较多轮廓的图片
2. 完成基础预处理和轮廓提取
3. 先把所有轮廓画出来，观察噪声和误检
4. 设计第一条过滤规则，例如最小面积
5. 再加入长宽比、近似边数等规则
6. 每加一条规则都观察结果变化
7. 最终保留你真正关心的轮廓并标注出来
8. 在 C++ 中复现同样的过滤逻辑

## 需要观察的点

- 哪些小轮廓明显是噪声
- 最小面积阈值改变时结果如何变化
- 长宽比规则是否会误杀真实目标
- 同一组规则在另一张图上是否仍然有效
- Python 与 C++ 的最终保留结果是否一致

## 预期效果

完成后你应该能：

- 明确说出你设计了哪些过滤规则
- 解释每条规则为什么存在
- 说明哪些轮廓被过滤掉，哪些被保留
- 输出一张只标出有效目标的结果图

## 常见问题

### 1. 过滤太严格

表现为：

- 连真正目标都被去掉了

说明你需要降低门槛或减少规则叠加。

### 2. 过滤太宽松

表现为：

- 噪声和背景碎片还大量存在

说明你需要增加更稳定的几何约束。

### 3. 一张图上有效，换图就失效

说明当前规则过度依赖某一张图，泛化性不足。

## 拓展练习

1. 对比只用面积过滤和“面积 + 长宽比”过滤的差异
2. 试着记录每个轮廓的面积分布，再决定阈值
3. 用两张不同图片测试同一组规则的稳定性
4. 在结果图上显示每个保留轮廓的面积数值
