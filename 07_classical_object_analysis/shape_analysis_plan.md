# Shape Analysis Plan

## 目标

这个计划文件不是给你代码，而是帮你在动手之前把实验目标说清楚：你到底想从一张图里分析出什么、为什么、以及如何判断结果是否可信。

## 推荐任务 1：形状分析主流程

### 任务描述

从一张静态图片中提取主要目标区域，并为每个保留目标计算基本几何特征。

### 你需要输出的内容

- 目标轮廓
- 包围框
- 面积
- 周长
- 长宽比
- 轮廓数量统计

### 适合的素材

优先尝试：

- `resources/photos/cat.jpg`
- `resources/photos/cats.jpg`
- `resources/photos/cats 2.jpg`

如果背景过于复杂，也可以后续补充规则图形素材。

## 推荐任务 2：轮廓过滤流程

### 任务描述

不是把所有轮廓都画出来，而是设计规则，只保留你真正关心的那些目标。

### 可尝试的过滤规则

- 最小面积
- 最大面积
- 包围框长宽比范围
- 轮廓近似边数
- 是否接近图像边缘

### 你要回答的问题

- 为什么这个轮廓应该保留？
- 为什么那个轮廓应该被过滤掉？
- 如果换一张图，当前规则是否还成立？

## 建议的实现顺序

1. 先确定输入图片
2. 先只做预处理和轮廓提取
3. 在没有过滤的情况下看所有轮廓
4. 再逐步加过滤规则
5. 最后做可视化和结果解释

## 验证清单

完成后至少检查下面这些点：

- 是否提取到了主要目标，而不是被大量噪声淹没
- 小碎片轮廓是否被合理过滤
- 面积和周长是否与视觉直觉一致
- 包围框是否正确覆盖目标
- 换一张图片后规则是否仍然大致可用
- Python 与 C++ 版本是否针对同一任务给出相近结果

## 建议记录的实验结论

每做完一次实验，建议你写下：

1. 你选了哪张图
2. 你用了 threshold 还是 Canny
3. 你用了哪些过滤规则
4. 哪些规则最有效
5. 哪些失败案例最值得记录

- `python/shape_analysis_pipeline.py`

目标：

- 快速完成实验闭环
- 快速比较不同参数效果

### C++

- `cpp/shape_analysis_pipeline.cpp`
- `cpp/contour_filtering_pipeline.cpp`

目标：
