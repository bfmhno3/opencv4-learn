# 实验：经典人脸识别

## 实验目标

基于已有训练集和验证集，理解经典人脸识别的基本闭环，并学会分析识别成功与失败的原因。

## 对应代码

- Python：`python/face_recognition_with_lbph.py`
- C++：`cpp/face_recognition_with_lbph.cpp`

## 第一性原理

这次实验的基线目标不是先做完整“检测 -> 识别”系统，而是先直接利用已经整理好的 `resources/faces/train/` 和 `resources/faces/val/` 数据，把经典识别闭环跑通。

人脸识别的核心不是直接“看整张图猜是谁”，而是：

1. 先保证训练样本和验证样本的标签是可靠的
2. 再把每张人脸样本和某个标签对应起来
3. 最后比较新样本与已知样本模式的相似性

等你把这条基线跑通之后，再把检测阶段接进来，观察 ROI 稳定性会怎样影响识别结果。

所以识别效果依赖于：

- 样本质量
- 标签是否正确
- train / val 是否真正分开
- 后续接入检测时 ROI 是否稳定

## 实验步骤

1. 浏览 `resources/faces/train/` 和 `resources/faces/val/`
2. 建立类别名与数值标签之间的映射
3. 从训练集中读取样本并准备训练数据
4. 训练经典识别器
5. 从验证集中读取样本并做预测
6. 记录预测结果、错误案例和可能原因
7. 用相同数据和思路在 C++ 中复现

## 需要观察的点

- 不同人物的样本数量是否平衡
- 同一人物在不同光照、姿态下是否容易被混淆
- 标签映射是否存在命名不一致问题
- 在后续把检测阶段接进来时，ROI 不稳定是否会让识别结果变差

## 预期效果

完成后你应该能：

- 解释训练集和验证集各自的作用
- 完成一个可运行的经典识别实验
- 分析至少几种常见错误来源
- 明白“能跑通”与“结果可信”不是同一个概念

## 常见问题

### 1. 训练数据读进来了，但标签混乱

通常说明目录名解析或标签映射规则不一致。

### 2. 识别准确率很低

不要第一时间怀疑算法本身，也要检查：

- 输入样本是否一致
- ROI 是否稳定
- 训练 / 验证是否混淆
- 部分类别样本是否过少

### 3. 检测正确但识别错误

这说明识别阶段的特征表达或训练数据质量还不够稳定。

## 拓展练习

1. 先只挑 2~3 个人做小规模实验，再扩展到更多类别
2. 记录每个类别最容易出错的样本类型
3. 比较“先检测再裁剪 ROI”与“直接使用现成样本”两种流程的差异
4. 对照 Python 与 C++ 两个版本，比较数据准备环节谁更容易出错
