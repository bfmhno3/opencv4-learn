# 实验：经典人脸检测

## 实验目标

理解经典人脸检测的基本流程，并学会通过参数调节观察误检、漏检与检测稳定性。

## 对应代码

- Python：`python/face_detection_with_haar.py`
- C++：`cpp/face_detection_with_haar.cpp`

## 第一性原理

人脸检测的目标不是“识别是谁”，而是先回答：

- 这张图里哪里可能有人脸？

在经典方法里，你通常不是依赖深度模型，而是利用亮度结构、局部模式和滑动窗口式思想来寻找符合条件的区域。

## 实验步骤

1. 先选择测试图片，可以优先尝试：
   - `resources/photos/group 1.jpg`
   - `resources/photos/group 2.jpg`
   - `resources/faces/val/` 中的部分图片
2. 读取图像并转成灰度图
3. 加载 Haar Cascade 分类器
4. 运行检测并得到候选人脸框
5. 把检测框画回原图
6. 调整关键参数，观察结果变化
7. 用相同思路在 C++ 中复现

## 需要观察的点

- 图片里人脸大小变化是否影响检测结果
- 角度、遮挡、光照是否导致漏检
- 背景中的非人脸区域是否会被误检
- 参数调大或调小时，误检和漏检如何变化

## 预期效果

完成后你应该能：

- 在多人图或单人图上画出检测框
- 比较不同参数下的检测效果
- 解释哪些失败属于误检，哪些属于漏检

## 常见问题

### 1. 完全检测不到人脸

通常需要检查：

- 分类器是否正确加载
- 图片是否转成灰度图
- 参数是否过于严格

### 2. 检测框太多

通常说明：

- 参数过于宽松
- 背景结构与人脸结构发生混淆

### 3. 多人图中远处人脸容易漏掉

通常是因为小尺寸目标更难被稳定检测。

## 拓展练习

1. 用同一组参数比较 `group 1.jpg` 和 `group 2.jpg`
2. 比较单人图和多人图的检测难度
3. 记录一组“误检最多”的参数和一组“漏检最多”的参数
4. 对比 Python 与 C++ 版本在参数调试体验上的差异
